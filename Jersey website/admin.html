PRIVATE STORE TOOLS

Inventory & orders.

This page is for the shop owner, not customers. Use it to enter stock counts for each size and review or update incoming order requests.

  1. Enter the owner access code printed in the PowerShell window that started the shop server.
  2. To update stock, open a jersey row, enter the quantity for each size, then choose Save Stock. Use 0 for sold out; leave blank if you are not tracking that size yet.
  3. To process an order, open it and change its status. Confirming deducts tracked stock; cancelling a confirmed order returns it.
  4. If you need to create a fresh access code, follow the admin setup steps.

The server owner sets this private code when starting the backend. It stays in this browser tab and protects customer order details; never share or commit it.

STORE MANAGEMENT

Inventory & orders.

Quick guide

  1. Open a product row. Enter how many you have in each size, then choose Save Stock.
  2. Leave a size blank if you are not tracking it. Enter 0 if sold out.
  3. Open an order under Recent orders to review the jersey, size, badge, customer, and delivery address.
  4. Confirm only when ready; confirmation deducts stock. Mark it dispatched after sending, or completed when done. Cancelling a confirmed order restores stock.
